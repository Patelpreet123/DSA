# [Level of a Node in Binary Tree](https://www.geeksforgeeks.org/problems/level-of-a-node-in-binary-tree/1)
## Easy
Given a Binary Tree and a target key, you need to find the level of the target key in the given Binary Tree.
Note: The level of the root node is 1. If given key does not exist, then return 0.
Examples:
Input: root = [1, 2, 3, 4, 5, N, N], target = 4

Output: 3Explanation: The level of target in above tree is 3.
