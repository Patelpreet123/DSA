# [Sorted Insert in DLL](https://www.geeksforgeeks.org/problems/insert-in-sorted-way-in-a-sorted-dll/1)
## Medium
Given a sorted doubly linked list and an element x, you need to insert the element x into the correct position in the sorted Doubly linked list(DLL).
Note: The DLL is sorted in ascending order
Example:
Input: LinkedList: 3-&gt;5-&gt;8-&gt;10-&gt;12 , x = 9Output: 3-&gt;5-&gt;8-&gt;9-&gt;10-&gt;12Explanation: Here node 9 is inserted in the Doubly Linked-List.
Input: LinkedList: 1-&gt;4-&gt;10-&gt;11 , x = 15Output: 1-&gt;4-&gt;10-&gt;11-&gt;15
Constraints:1 ≤ number of nodes ≤ 1031 ≤ node -&gt; data , x ≤ 104
