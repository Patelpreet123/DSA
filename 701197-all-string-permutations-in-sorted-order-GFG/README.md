# [All String Permutations in Sorted Order](https://www.geeksforgeeks.org/problems/permutations-of-a-given-string-1587115620/1)
## Hard
Given a string s. Find all permutations &nbsp;of a given string. Return the permutations in lexicographically non-decreasing order.
Examples :
Input: s = "AA"
Output: ["AA", "AA"]Explanation: There are total 2 permutations, as given in the output.

Input: s = "ABC"
Output: ["ABC", "ACB", "BAC", "BCA", "CAB", "CBA"]Explanation: There are total 6 permutations, as given in the output.
Constraints:1 ≤ s.size() ≤ 5
